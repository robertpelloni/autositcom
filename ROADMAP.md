# ROADMAP.md
## Structural Milestones

### Phase 1: MVP Pipeline (Current)
- Complete basic end-to-end flow from audio ingestion to mock publishing.
- Establish core containerized architecture.
- Implement unified UI dashboard for monitoring.

### Phase 2: Enhanced Rendering & Auth
- Implement full OAuth flows for YouTube, TikTok, and X to replace mock APIs.
- Upgrade video composer to use dynamic background images generated via DALL-E or Midjourney APIs.
- Implement true speaker diarization in the transcription phase using `pyannote.audio`.

### Phase 3: Continuous Broadcast & Monetization
- Transition publisher from VOD uploads to a continuous 24/7 RTMP stream (Twitch/YouTube Live).
- Integrate dynamic ad insertion or sponsor shoutouts generated by the scriptwriter.
- Transition to a microservice architecture communicating via Redis or RabbitMQ for infinite horizontal scaling.
